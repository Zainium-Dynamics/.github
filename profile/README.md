# A deterministic, musl-native operating system

![Zainium OS](https://raw.githubusercontent.com/Zainium-Dynamics/.github/main/profile/zainium-os.png)

Zainium Dynamics builds [ZainiumOS](https://github.com/Zainium-Dynamics/ZainiumOS), an independent Linux operating system made from scratch on musl libc and not derived from any other distribution. The base system and the software you install live in separate layers under `/overlayer` and are joined at boot with OverlayFS, so nothing you install can change the base. Around it we make the tools the system runs on: the package manager zex, the initramfs [quantra-ramfs](https://github.com/Zainium-Dynamics/quantra_ramfs), [elevate](https://github.com/Zainium-Dynamics/elevate) in place of sudo, [sys_resolver](https://github.com/Zainium-Dynamics/sys_resolver) for programs that expect the usual Linux paths, and the package recipes in [syshub-recipes](https://github.com/Zainium-Dynamics/syshub-recipes), [userland-recipes](https://github.com/Zainium-Dynamics/userland-recipes) and [cosmic-zainium](https://github.com/Zainium-Dynamics/cosmic-zainium).

We also write memory-safe Rust replacements for classic system software, such as [oxibus](https://github.com/Zainium-Dynamics/oxibus) for D-Bus, [oxipd](https://github.com/Zainium-Dynamics/oxipd) for dhcpcd, [oxicurses](https://github.com/Zainium-Dynamics/oxicurses) for ncurses, [oxiread](https://github.com/Zainium-Dynamics/oxiread) for line editing, [elevate-umbra](https://github.com/Zainium-Dynamics/elevate-umbra) for shadow-utils, [oxidized-environment](https://github.com/Zainium-Dynamics/oxidized-environment) for `/etc/profile.d` and [oxidized-yacc](https://github.com/Zainium-Dynamics/oxidized-yacc) for parser generation, along with projects like [Recoil](https://github.com/Zainium-Dynamics/Recoil), [vaultion](https://github.com/Zainium-Dynamics/vaultion), [eclipse-bootloader](https://github.com/Zainium-Dynamics/eclipse-bootloader), [eclipse-comp](https://github.com/Zainium-Dynamics/eclipse-comp) and the [Evorix browser](https://github.com/Zainium-Dynamics/Evorix-browser).

Our first rule is determinism: the same inputs should give the same build, install and upgrade, every time. ZainiumOS is free software under the GPL-3.0 and in active development.
